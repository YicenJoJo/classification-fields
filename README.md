# Classification Fields

**Arbitrarily Fine Recursive Hierarchical Clustering From Few Examples**

Code for learning a local refinement rule from a finite hierarchy and recursively generating deeper levels.

[Paper](https://openreview.net/forum?id=dLTzQWpUx2)

## Method

A classification field predictor maps a parent centre to an ordered set of child residuals. Starting from a root, the hierarchy is generated by

$$
x_{\alpha k} = x_\alpha + s^{|\alpha|+1}\,\hat r(x_\alpha)_k.
$$

The predictor is trained on observed parent–child pairs and evaluated by recursive rollout. Experiments cover CFG-generated hierarchies, affine and nonlinear IFS fractals, and hierarchies constructed from CIFAR-10/100 CLIP embeddings.

## Setup

Use Python 3.11 and a CUDA-enabled PyTorch installation for the image experiments.

```bash
git clone https://github.com/YicenJoJo/classification-fields.git
cd classification-fields
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows, activate the environment with `.venv\Scripts\Activate.ps1`.

## Experiments

| Script | Experiments |
|---|---|
| `synthetic_benchmarks.py` | Affine IFS benchmarks; training-depth, scale, branching-factor and child-order ablations |
| `synthetic_benchmarks_nonlinear_ifs.py` | Nonlinear Sierpiński, Cantor dust, Koch curve and random IFS benchmarks |
| `cifar_clip.py` | Matched CFG extrapolation, followed by CIFAR-100 and CIFAR-10 with CLIP and recursive SCP |

### IFS benchmarks

Models observe levels 0–2 and predict levels 3–5. Each suite runs five trials and compares CFP with affine, learnable-constant and average-residual baselines.

```bash
python run_experiment.py affine --output results/affine
python run_experiment.py nonlinear --output results/nonlinear
```

### CIFAR and matched CFG experiments

The image pipeline extracts frozen CLIP ViT-B/32 features, constructs ternary SCP hierarchies, and trains a GELU bottleneck predictor with width 1024 and seven hidden layers. CIFAR images and CLIP weights are downloaded on the first run.

```bash
python run_experiment.py cifar --output results/cifar
```

This script first runs the matched CFG experiment with nine trials, then the CIFAR-100 and CIFAR-10 experiments with seeds 42–46. Image predictors train on levels 0–5; metrics are exported separately for each available held-out level. The level-6 rows correspond to the evaluation depth in Table 2.

### Ablations

```bash
python run_experiment.py depth --output results/depth
python run_experiment.py scale --output results/scale
python run_experiment.py branching --output results/branching
python run_experiment.py ordering --output results/ordering
```

The synthetic predictor uses a ReLU MLP with three hidden layers of width 64. IFS runs use 2,000 training epochs; CFG runs use 3,000. The base Adam learning rate is 0.001.

## Outputs

Each run writes figures and CSV metrics to its output directory. Reported metrics are coordinate-averaged MSE, symmetric squared Chamfer distance (PI-CD), and diameter-normalized tree-path distortion. Lower values indicate better agreement.

| Experiment | Main CSV files |
|---|---|
| IFS | `fractal_benchmark_breakdown.csv`, `fractal_main_table.csv` |
| Matched CFG | `extrapolation_summary.csv` |
| CIFAR | `cifar_scp_5seed_trials.csv`, `cifar_scp_5seed_summary.csv` |

The original script environment variables remain available: `EXP_RESULTS_DIR`, `EXP_RUN_FRACTAL`, `EXP_RUN_LTRAIN_SWEEP`, `EXP_RUN_S_ABLATION`, `EXP_RUN_K_ABLATION`, `EXP_RUN_PERM_CHECK`, `EXP_CIFAR_N_TRIALS`, and `EXP_CIFAR_BASE_SEED`.
